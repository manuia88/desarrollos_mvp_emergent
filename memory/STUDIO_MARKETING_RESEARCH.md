## Phase Z arquitectura final · 9 sub-chunks · 224h Wave 5 H2

### Z.1 Brand Kit + Listing Importer + Asset Library (16h)

- Brand kit centralizado per usuario (logo · colores · fonts · disclaimer · CTA defaults · 4 variantes branding)
- URL portal import: Inmuebles24 · Lamudi · Vivanuncios · Propiedades.com · EasyBroker · Casas y Terrenos
- Asset library MongoDB GridFS + Cloudflare R2 (fotos · videos · PDFs · 3DGS scans)
- Per-project mood board (concept Grazia)

### Z.2 Buyer-angle copy + Carrusel auto (18h)

- 7 personas LATAM: Inversor · Familia · First-buyer · Exec · Extranjero/Expat · Jubilado · Empty-nester
- DISC-adapted script per persona
- Carrusel auto (hero + N stats + CTA · 4 aspect ratios · brand kit)
- Auto-content diario (modelo Mirino) con datos BANXICO/Zone Score/demand-supply

### Z.3 Multi-channel Publisher + Scheduler (36h · subsumed por W5.10)

- OAuth multi-platform (Meta · Google/YouTube · TikTok · WA Business · LinkedIn)
- Posting engine FB · IG · Stories · Reels · YT · YT Shorts · WA Status · TikTok · LinkedIn
- Calendar drag-drop scheduler + auto-repost intelligence
- Cross-post automático (Reel IG → YT Shorts mismo MP4)

### Z.4 Video engines + Avatares + Voice clone + Virtual Staging (42h)

- Photo→video (Fal Kling/Seedance · alternativa Replicate)
- Camera path foto→recorrido 30s (Kling motion control)
- Cinematic 10 presets RE-specific (Drone reveal · Hero zoom · Walkthrough · Sunset-to-night · Empty-to-staged · etc.)
- Avatar UGC pre-curados 10-15 ES-MX (vía HeyGen API)
- **Avatar custom asesor** (HeyGen Instant Avatar · selfie/video 2min → su avatar IA)
- Voice clone asesor real (ElevenLabs · 2 min sample → su voz)
- Lip-sync con voz clone
- Virtual Staging 5 variantes (Replicate decoratorai o Fal Flux Kontext):
  1. Empty → staged amueblado
  2. Day → night/twilight
  3. Object removal (declutter)
  4. Grass green-up
  5. Sky replacement

### Z.5 Hook/Virality predictor (6h)

- LLM rubric 0-100 (hook strength · clarity · CTA · novelty)
- Real estate engagement model trained sobre posts MX prensa
- Pre-publish gating: post score >70 = green light · <50 = rewrite suggestion

### Z.6 ML Closed-Loop System (30h · expandido +20h)

- Multi-armed bandit per buyer-angle × DISC × zona
- Bayesian optimization budget allocation
- Ensemble predictor CTR · CPL · conversion (pre-flight prediction)
- Real-time optimization (24h ad performance check · auto-rebalance)
- Cohort learning anónimo (asesores similares aprenden mutuo · federated style)
- Causal inference (statistical significance A/B)
- **DMX Index público** (top creatives MX por categoría · anónimo · prensa cita)

### Z.7 Workflow Builder UI (20h)

- Drag-drop canvas trigger → action
- 20+ triggers RE: lead events · journey steps · saved zones · notifs · cron · webhooks · price changes · post engagement
- 15+ actions: Send WA · email · notif · reassign asesor · adjust price · run AI tool · post social · update CRM field
- 10-15 templates pre-built RE
- Versioning + activate/deactivate flag + audit log

### Z.8 Landing Pages Profesionales (32h · expandido +16h)

- 10 templates premium curados (Luxury · Modern · Family · Investor · Boutique · Urgent · Scrollytelling · Video-first · Social proof · Compare)
- IA composer: LLM compone copy persuasiva (7 buyer-angles) + brand kit
- Componentes embebibles: Hero (foto/video/3DGS auto) · Gallery · Specs grid · Brochure DL · Video tour · 3DGS · Floor plan + staging · Map zone score · ROI calculator (W4.14) · Testimonials · Asesor card video selfie · Lead form WA UTM · WA click-to-chat float · FAQs · brand kit · og:image dinámico · indexable Google · sitemap per asesor
- Drag-drop section editor
- Subdomain DMX wildcard `*.dmx.io` (Cloudflare DNS + SSL Let's Encrypt auto)
- Custom domain Pro tier ($50/mo · CNAME setup)

### Z.9 Wallet + Metering + Stripe Pay-as-you-go (24h)

- Modelo aggregator (DMX paga APIs · usuario carga créditos a wallet DMX)
- MongoDB `user_wallet` { user_id · balance_mxn · balance_usd · transactions[] · low_balance_alert · auto_recharge }
- Metering layer per API (Replicate · HeyGen · Fal · ElevenLabs · Luma · Higgsfield)
- Real-time balance check antes API call
- Stripe MX checkout (credit/debit + OXXO + SPEI)
- Packages: $200/$500/$1000/$5000 MXN
- Tiers: Free $0 (5 brochures/mes throttled) · Pay-as-you-go libre · Pro $499/mo (600 credits) · Enterprise custom
- Dashboard wallet usuario (saldo · histórico · proyección · alertas)
- Founder dashboard superadmin (cost real per API · margin · top spenders · health · rate limits)
